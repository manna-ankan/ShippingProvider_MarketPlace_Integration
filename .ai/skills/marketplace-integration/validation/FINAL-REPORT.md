## TRUE ARCHITECTURE (evidence-backed)

- Mongo collection `source` + embedded connectors/config (`Source.java` `@Document(collection="source")`)
- Tenant `Channel` created later via admin — not generated by skill
- Scraper XML scripts wired by `sourceProperties` script-name keys
- Polling baseline: order import + inventory crons; list→details→`CreateSaleOrderRequest`
- Inventory failures via `#failedInventorySnapshots` / `ChannelScriptError`
- Status mapping primarily **in-script**
- Connector verification → `PersistentParams` for token persistence
- Optional `utils.script` convention; multi-connector supported
- Inbound webhooks via `UniwareWebhookService` (`__data`) — **do not** replace list script when order sync ON
